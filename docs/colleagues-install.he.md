# התקנת Klara Wisper

Klara Wisper מתמללת פגישות והכתבות בעברית, ישר על המחשב. שום אודיו לא יוצא מהמחשב.

ההתקנה עושה הכל לבד: בודקת את המחשב, שואלת שתי שאלות, בוחרת את הגרסה שמתאימה למחשב, מורידה את מנוע התמלול, מתחברת ל-Claude ובודקת שהכל עובד. צריך רק ללחוץ "המשך".

את הקבצים מורידים מדף הגרסאות: https://github.com/klara-gidash/klara-wisper/releases/latest

---

# מק

## מה צריך

- מק עם שבב Apple (M1 ומעלה), macOS 14.4 ומעלה. אם המחשב לא מתאים, ההתקנה עוצרת ואומרת למה.
- כ-6GB פנויים וחיבור לאינטרנט בפעם הראשונה.

## התקנה

1. מורידים את **`Klara Wisper.pkg`** ולוחצים עליו פעמיים.
2. בפעם הראשונה macOS עוצר את הקובץ, כי לתוכנה אין חתימה של מפתח רשום אצל Apple. זה צפוי, ועושים את זה פעם אחת:
   - לוחצים **"סיום"** (Done) בהודעה.
   - פותחים את  ← **הגדרות המערכת** ← **פרטיות ואבטחה**, גוללים למטה ולוחצים **"פתח בכל זאת"** (Open Anyway) ליד Klara Wisper.pkg, ומאשרים עם סיסמה או Touch ID.
   - ב-macOS 14 אפשר במקום זה ללחוץ על הקובץ בלחיצה ימנית ← **פתח** ← **פתח**.
3. בחלון ההתקנה: **המשך** ← **התקן**, ומאשרים עם הסיסמה של המק.
4. בסוף Klara Wisper נפתחת לבד, והמדריך שבתוכה ממשיך מכאן (למטה: "המדריך בתוך התוכנה").

יש גם `Klara Wisper.dmg`, למי שמעדיף לגרור את התוכנה לתיקייה Applications. אם היא נפתחת ישר מתוך ה-dmg, המדריך מציע להעביר אותה ל-Applications בלחיצה אחת.

## עדכון

מורידים את ה-pkg החדש ומתקינים אותו כמו בפעם הראשונה. אם Klara Wisper פתוחה, ההתקנה סוגרת אותה (ושומרת הקלטה שבאמצע) ופותחת אותה שוב בסוף. ההגדרות, המודלים והתמלולים נשמרים. אחרי עדכון macOS עשוי לבקש שוב חלק מההרשאות.

## הסרה

Klara Wisper ← הגדרות ← מנוע התמלול ← **הסרת Klara Wisper**. זה מסיר את התוכנה, המנוע והמודלים (כ-3.5GB), ההגדרות, טביעות הקול, ההרשאות והחיבור ל-Claude. התמלולים ב-`~/Documents/Klara Wisper` נשארים.

# Windows

## מה צריך

- Windows 10 (22H2) או Windows 11, 64 ביט. אם המחשב לא מתאים, ההתקנה עוצרת ואומרת למה.
- כ-6GB פנויים וחיבור לאינטרנט בפעם הראשונה. לא צריך הרשאות מנהל.

## התקנה

1. מורידים את **`Klara Wisper Setup.exe`** ולוחצים עליו פעמיים.
2. לקובץ אין חתימה דיגיטלית, ולכן Windows עשוי להציג "Windows protected your PC". לוחצים **More info** (מידע נוסף) ואז **Run anyway** (הפעל בכל זאת).
3. ההתקנה לוקחת כמה שניות, יוצרים קיצור דרך על שולחן העבודה, ו-Klara Wisper נפתחת לבד עם המדריך.
4. אם במחשב חסר רכיב של Microsoft שהתמלול צריך (Visual C++), התוכנה מורידה אותו מ-Microsoft ו-Windows שואל פעם אחת "לאפשר לאפליקציה לבצע שינויים?". לוחצים **כן**.

## עדכון

מורידים את `Klara Wisper Setup.exe` החדש ומריצים אותו. ההגדרות, המודלים והתמלולים נשמרים.

## הסרה

הגדרות ← אפליקציות ← Klara Wisper ← **הסרה** (או מתוך Klara Wisper: הגדרות ← מנוע התמלול ← **הסרת Klara Wisper**). זה מסיר גם את המנוע, המודלים, ההגדרות והחיבור ל-Claude. התמלולים ב-`Documents\Klara Wisper` נשארים.

## הבדלים מהמק

- הצד השני בשיחה מוקלט מכל מה שהמחשב משמיע. כדאי להשתיק מוזיקה וסרטונים בזמן שיחה.
- היומן מגיע מ-Google Calendar (קישור פרטי שמדביקים פעם אחת). בלי יומן, ההקלטות נקראות לפי האפליקציה (Zoom, Meet, Teams).
- התמלול רץ על המעבד, ולכן הוא איטי יותר מאשר במק.
- הכתבה: מחזיקים את **Ctrl הימני**, מדברים ומשחררים.

# המדריך בתוך התוכנה (מק ו-Windows)

בכל שלב יש כפתור אחד גדול. ברירת המחדל היא תמיד ההמלצה, אז אפשר פשוט ללחוץ "המשך".

1. **בדיקת המחשב:** מעבד, זיכרון, מקום פנוי, גרסת מערכת וחיבור לאינטרנט. המחשב מסווג כ"חזק", "רגיל" או "קל". אם משהו לא מתאים, כתוב מה ולמה.
2. **שתי שאלות:** במה תשתמשו (הכתבה, שיחות אונליין, פגישות פנים מול פנים), ובאיזו שפה מדברים (בעיקר עברית, או עברית ואנגלית). לפי התשובות והמחשב נבחרת הגרסה:

   | מחשב | מה מותקן |
   |---|---|
   | מק רגיל (8–24GB) | מודל התמלול העברי של ivrit.ai (המהיר והמדויק ביותר לעברית) |
   | מק חזק (Pro / Max / Ultra או 32GB+) | כמו רגיל; עם "עברית ואנגלית" אפשר לבחור "דיוק מרבי" (Whisper large-v3) |
   | מחשב קל (8GB, או PC חלש) | בלי זיהוי דוברים בשיחות אונליין, כדי שהמחשב לא יאט בזמן שיחה |
   | Windows | המודל העברי של ivrit.ai בגרסה למעבד (CTranslate2) |
   | רק הכתבה | רק מודל התמלול, בלי מודלי זיהוי הדוברים, והקלטה אוטומטית של שיחות כבויה |

3. **התקנה:** הכל יורד לבד, כ-2–2.5GB. אפשר להמשיך לשלבים הבאים בינתיים ואפשר לעזוב את המחשב: המחשב לא נכנס לשינה באמצע, ואם האינטרנט נופל, ההורדה מחכה וממשיכה מאיפה שעצרה. אם הדיסק מלא או שרשת החברה חוסמת, כתוב מה לעשות.
4. **הרשאות:** במק, macOS שואל על כל הרשאה (מיקרופון, אודיו מערכת, נגישות, ניטור קלט, יומן, דפדפנים). ב-Windows רק מיקרופון.
5. **יומן** (כשמשתמשים בשיחות או בפגישות): כדי שכל שיחה תקבל את שם הפגישה והמשתתפים. במק: היומן של המק (כל החשבונות שמחוברים אליו), או יומן Google ישירות. ב-Windows: יומן Google, דרך "כתובת סודית בפורמט iCal" שמעתיקים פעם אחת מההגדרות של Google Calendar ומדביקים במדריך. הקישור נשמר מוצפן במחשב. אפשר לדלג ולחבר אחר כך בהגדרות.
6. **שם וטביעת קול** (כשיש זיהוי דוברים): הקלטה קצרה, כדי שהתוכנה תזהה אתכם בפגישות פנים מול פנים.
7. **Claude:** החיבור נעשה לבד: Claude Desktop, Claude Code והסקילים. אם Claude פתוח, כפתור אחד מפעיל אותו מחדש. אם Claude לא מותקן, יש כפתור להורדה, והחיבור קורה לבד בפעם הבאה ש-Klara Wisper נפתחת. מי שלא רוצה, לוחץ "לא לחבר ל-Claude".
8. **בדיקת תקינות:** המנוע עולה, משפט בעברית מתומלל, המיקרופון זמין, היומן מחובר, Claude מתחבר ויש מקום לשמירה. אם משהו נכשל, כתוב מה לעשות, ויש כפתור **תיקון אוטומטי** שבונה את המנוע מחדש. **העתקת דוח לתמיכה** מעתיק דוח קצר (בלי תמלולים, בלי שמות ובלי הגדרות אישיות) להדבקה במייל.

את בדיקת התקינות אפשר להריץ שוב בכל רגע: הגדרות ← בדיקת תקינות.

## משהו לא עובד?

1. הגדרות ← בדיקת תקינות ← **תיקון אוטומטי**.
2. אם זה לא עזר: **העתקת דוח לתמיכה**, ושולחים למי שעוזר בהתקנה, או פותחים issue במאגר ב-GitHub.
