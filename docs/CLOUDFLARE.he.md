# Klara Wisper בענן: לשאול את Claude מהטלפון, ולהקליט מהטלפון

## מה זה עושה

בדרך כלל Klara Wisper שומרת הכול על המחשב, ו-Claude קורא את השיחות דרך חיבור מקומי. החיבור הזה עובד רק ב-Claude Desktop וב-Claude Code על אותו מחשב, ולכן Claude בטלפון לא מגיע אליו.

הענן הוא תוספת רשות, והוא כבוי עד שמפעילים אותו. הוא נותן שני דברים:

1. **לשאול את Claude על השיחות מהטלפון.** Klara Wisper מעלה את התמלולים והסיכומים (טקסט), וב-claude.ai מוסיפים connector שיכול רק לקרוא אותם.
2. **קישור הקלטה לטלפון.** קישור שפותחים בטלפון, לוחצים, והוא מקליט לענן. מתאים לפגישה פרונטלית או לשיחת טלפון ברמקול כשהמחשב לא לידך.

הכול נמצא **בחשבון Cloudflare פרטי שלך**: מסד נתונים קטן ושרת קטן (Worker). אין שרת משותף ואין צד אחר שמנהל אותו. התוכנית החינמית של Cloudflare מספיקה לשימוש אישי, ולא צריך להזין אמצעי תשלום.

## הקמה אוטומטית (מומלץ)

1. אם אין חשבון Cloudflare, נרשמים בחינם ב-https://dash.cloudflare.com/sign-up ומאשרים את המייל.
2. ב-Klara Wisper: **הגדרות** ← **ענן** ← **"הגדרה אוטומטית"**.
3. לוחצים על הקישור שהאפליקציה מציגה. הוא פותח את Cloudflare עם **API token** שההרשאות שלו כבר ממולאות (רק מה שצריך כדי ליצור את מסד הנתונים ואת ה-Worker). לוחצים **Continue to summary** ← **Create Token**, ומעתיקים את ה-token.
4. מדביקים את ה-token ב-Klara Wisper ולוחצים **"הקמה"**. האפליקציה יוצרת בחשבון שלך את מסד הנתונים ואת ה-Worker, ויוצרת לבד את שלושת הטוקנים (ראו "שלושת הטוקנים" בהמשך).
5. בסוף מופיעים שני דברים:
   - **כתובת ה-connector ל-Claude**: מוסיפים אותה ב-claude.ai (הסבר בסעיף "ב-claude.ai").
   - **קישור ההקלטה לטלפון**: פותחים אותו בטלפון (הסבר בסעיף "הקלטה מהטלפון"). אפשר לסרוק את קוד ה-QR שמופיע לידו.
6. לוחצים **"סנכרון כל השיחות"** כדי להעלות את השיחות שכבר נשמרו. מכאן כל שיחה עולה לבד אחרי שהיא נשמרת, ושוב כשהיא מתעדכנת (סיכום, שם, משתתפים).

את ה-API token אפשר למחוק ב-Cloudflare אחרי ההקמה: האפליקציה לא צריכה אותו כדי לעבוד. כדי לעדכן את ה-Worker או להחליף את קישור הטלפון בעתיד, יוצרים מפתח חדש מאותו קישור ומדביקים אותו (או מסמנים "לשמור לעדכונים" בזמן ההקמה).

**הקמה מחדש** (במחשב נוסף, או אחרי "ניתוק המחשב מהענן"): אם כבר יש Worker בחשבון, האפליקציה עוצרת ושואלת קודם. הקמה חדשה מחליפה את שלושת המפתחות, ולכן מחשב אחר שמסונכרן עם ה-Worker יפסיק לסנכרן, וצריך להוסיף מחדש את ה-connector ב-claude.ai ואת הקישור בטלפון. אם המפתחות עדיין שמורים במחשב הזה, בוחרים "לעדכן ולשמור על המפתחות של המחשב הזה".

## שלושת הטוקנים

- **טוקן העלאה**: רק Klara Wisper במחשב משתמשת בו, כדי להעלות שיחות, להוריד הקלטות ולמחוק. הוא נשמר מוצפן במחשב ולא יוצא ממנו, חוץ מאשר ל-Worker עצמו.
- **טוקן קריאה**: נמצא בתוך כתובת ה-connector ב-claude.ai. מאפשר רק לקרוא שיחות.
- **טוקן הקלטה**: נמצא בתוך קישור ההקלטה בטלפון. מאפשר רק להעלות הקלטות, ולא לקרוא או לשמוע שום דבר.

## הקלטה מהטלפון

1. פותחים את קישור ההקלטה בטלפון: באייפון ב-Safari, באנדרואיד ב-Chrome.
2. מוסיפים אותו למסך הבית: באייפון **שיתוף** ← **הוספה למסך הבית**, באנדרואיד בתפריט ⋮ ← **הוספה למסך הבית**. מעכשיו זה אייקון עם נקודה אדומה, והקלטה היא לחיצה אחת.
3. אפשר לכתוב כותרת (רשות) ולבחור **פגישה פרונטלית** או **שיחת טלפון ברמקול**.
4. לוחצים על הכפתור הגדול. בפעם הראשונה הטלפון שואל אם לאשר את המיקרופון. בזמן ההקלטה המסך נשאר דלוק, ורואים שעון ומד עוצמה. **משאירים את הדף פתוח** עד שעוצרים.
5. לוחצים שוב כדי לעצור. כשמופיע **"הועלה ✓ — יתומלל במחשב שלך"**, אפשר לסגור.

מה קורה מאחורי הקלעים:

- ההקלטה עולה בחלקים קטנים, כל כ-10 שניות. כל חלק נשמר קודם בטלפון, ונמחק ממנו רק אחרי שהענן אישר שקיבל אותו. אם החיבור נופל, ההקלטה ממשיכה, והחלקים עולים כשהחיבור חוזר. אם הדף נסגר באמצע, בפעם הבאה שפותחים אותו מופיע כפתור **"להשלים את ההעלאה"**.
- האודיו מחכה בחשבון ה-Cloudflare שלך עד שהמחשב דולק ו-Klara Wisper פתוחה. אז היא מורידה אותו, מתמללת אותו **על המחשב, עם אותו מודל עברית**, ו**מוחקת אותו מהענן**. מה שנשאר הוא התמלול, כמו בכל שיחה אחרת (ואם הסנכרון פעיל, גם הוא עולה לענן כטקסט).
- הקלטה שלא הסתיימה תוך 7 ימים, או שחיכתה למחשב 30 יום, נמחקת מהענן לבד.
- באחסון בענן יש מקום לכ-400 MB של אודיו שממתין (בערך 25 שעות). אם הוא מתמלא, הטלפון מציג הודעה ושומר את ההקלטה אצלו עד שהמחשב יאסוף את מה שממתין.
- הקלטה אחת יכולה להימשך עד כ-4 שעות. אחר כך היא נעצרת לבד, ואפשר להתחיל חדשה.

טיפים:

- משאירים את הדף בחזית. אם נועלים את הטלפון או עוברים לאפליקציה אחרת, ההקלטה עלולה להיעצר (בעיקר באייפון). מה שכבר הוקלט לא אובד.
- **שיחת טלפון ברמקול:** הטלפון שמקליט צריך לשמוע את הרמקול. הכי טוב כשהשיחה עצמה רצה במכשיר אחר (טלפון שני, טלפון שולחני או מחשב). באייפון, שיחה סלולרית באותו טלפון עשויה לעצור את ההקלטה.
- את הקישור מעבירים לטלפון בדרך פרטית: סורקים את קוד ה-QR, או AirDrop, או הודעה לעצמך בלבד. לא שולחים אותו לקבוצה.

## לפני שמתחילים: מה מוותרים עליו בפרטיות

- **בלי הענן**, התמלולים והאודיו נמצאים רק על המחשב. **עם הענן**, עותק של התמלולים נשמר בחשבון ה-Cloudflare הפרטי, והקלטות מהטלפון נשמרות שם עד שהמחשב מתמלל אותן. Cloudflare מצפינה את המידע בשמירה, אבל הוא בכל זאת נמצא אצל ספק ענן.
- **כתובת ה-connector כוללת את טוקן הקריאה.** עם הכתובת הזאת אפשר לקרוא את כל השיחות, בלי שום סיסמה נוספת. פרטים באזהרה בסוף המסמך.
- **מי שיש לו את קישור ההקלטה יכול להעלות הקלטות** לחשבון שלך (אבל לא לקרוא או לשמוע כלום). שומרים אותו פרטי, ואפשר להחליף אותו בהגדרות ← ענן.
- בשיחות מדברים גם אנשים אחרים. לפני שמקליטים או מעלים שיחות עבודה לענן, כדאי לוודא שזה מתאים למדיניות של החברה ולמה שסוכם עם המשתתפים.
- כש-Claude קורא שיחה, התוכן עובר ל-Anthropic, בדיוק כמו בחיבור המקומי.
- אפשר להפסיק בכל רגע: מכבים את הענן ומוחקים את המידע (ההסבר בהמשך).

## ב-claude.ai

1. נכנסים ל-claude.ai בדפדפן במחשב ← **Settings** ← **Connectors** ← **Add custom connector**.
2. בשם כותבים `Klara Wisper`, ובכתובת מזינים:

   ```
   https://klara-wisper-gateway.<subdomain>.workers.dev/mcp/<TOKEN>
   ```

   בהקמה האוטומטית מעתיקים את הכתובת המלאה מ-**הגדרות** ← **ענן**. בהקמה ידנית, במקום `<TOKEN>` מדביקים את **טוקן הקריאה** (`KLARA_MCP_TOKEN`), ולא את טוקן ההעלאה. את ההגדרות המתקדמות (OAuth) משאירים ריקות.
3. לוחצים **Add**.
4. מאותו רגע ה-connector זמין גם באפליקציית Claude בטלפון, באותו חשבון. אם Claude לא משתמש בו, בודקים שהוא מופעל בתפריט הכלים של השיחה.

**חשבון ארגוני (Team או Enterprise):** ייתכן שרק חשבונות עם הרשאת ניהול יכולים להוסיף connector מותאם. connector שמוסיפים ברמת הארגון זמין לכל החשבונות בארגון, וטוקן הקריאה נמצא בתוך הכתובת. לכן כל חשבון בארגון שיחובר אליו יוכל לקרוא את השיחות. **לא מבקשים מצוות הניהול להוסיף את ה-connector לארגון.** במקום זה משתמשים בחשבון Claude אישי, או מתייעצים קודם עם צוות ה-IT.

## החלפת הטוקן

כדאי להחליף טוקן אם יש חשש שהוא דלף, וגם סתם מדי פעם. **הדרך הקלה:** ב-Klara Wisper ← **הגדרות** ← **ענן** יש כפתורים להחלפת כתובת ה-connector ולהחלפת קישור ההקלטה. ההוראות הבאות הן לדרך הידנית.

**אם קישור ההקלטה דלף** (טוקן ההקלטה): מריצים `openssl rand -hex 32`, ואז `npx wrangler secret put KLARA_REC_TOKEN` ומדביקים. הקישור הישן מפסיק לעבוד מיד. מעדכנים את הטוקן ב-Klara Wisper ופותחים בטלפון את הקישור החדש (ומוסיפים אותו שוב למסך הבית).

**אם כתובת ה-connector דלפה** (טוקן הקריאה):
1. מריצים `openssl rand -hex 32` ושומרים את הטוקן החדש.
2. מריצים `npx wrangler secret put KLARA_MCP_TOKEN` ומדביקים אותו. מהרגע הזה הכתובת הישנה מפסיקה לעבוד.
3. ב-claude.ai מסירים את ה-connector הישן ומוסיפים אותו מחדש עם הכתובת החדשה.

**אם טוקן ההעלאה דלף:**
1. מריצים `openssl rand -hex 32` ושומרים את הטוקן החדש.
2. מריצים `npx wrangler secret put KLARA_TOKEN` ומדביקים אותו.
3. ב-Klara Wisper, ב**הגדרות** ← **ענן**, מעדכנים את הטוקן.

## מחיקת כל המידע

קודם מכבים את הסנכרון ב-Klara Wisper, כדי שהשיחות לא יעלו שוב.

**כדי לרוקן את מסד הנתונים ולהשאיר את ה-Worker**, מריצים (עם הכתובת האמיתית ועם טוקן ההעלאה):

```
curl -X DELETE https://klara-wisper-gateway.<subdomain>.workers.dev/api/meetings \
  -H "Authorization: Bearer <UPLOAD_TOKEN>" -H "Content-Type: application/json" -d '{"all":true}'
```

התשובה היא `{"ok":true,"deleted":…}` עם מספר השיחות שנמחקו. הקלטות מהטלפון נמחקות מהענן לבד אחרי שהמחשב מתמלל אותן.

**כדי למחוק הכול לגמרי** (ה-Worker, מסד הנתונים, השיחות וההקלטות), מוחקים ב-https://dash.cloudflare.com את ה-Worker `klara-wisper-gateway` (‏Workers & Pages) ואת מסד הנתונים `klara-wisper` (‏D1), או מריצים מתוך התיקייה `cloudflare`:

```
npx wrangler delete
npx wrangler d1 delete klara-wisper
```

בסוף מסירים את ה-connector מ-claude.ai ואת האייקון ממסך הבית בטלפון.

## אזהרה: אסור לשתף את הכתובת

טוקן הקריאה נמצא בתוך הכתובת של ה-connector, ועם הכתובת הזאת **אפשר לקרוא את כל השיחות**, בלי שום סיסמה נוספת (אבל לא להעלות, לשנות או למחוק). לכן:

- לא שולחים אותה בצ'אט או במייל.
- לא מציגים אותה בשיתוף מסך.
- לא שומרים אותה במסמך משותף.

אם הכתובת דלפה, מחליפים את טוקן הקריאה מיד (הסבר בסעיף "החלפת הטוקן").

**קישור ההקלטה** פחות רגיש: מי שיש לו אותו יכול רק להעלות הקלטות לחשבון שלך, ולא לקרוא או לשמוע שום דבר. ובכל זאת שומרים אותו פרטי, ואם הוא דלף מחליפים אותו בהגדרות ← ענן.

את טוקן ההעלאה לא מכניסים לשום כתובת ולא משתפים בכלל. הוא נשמר רק ב-Klara Wisper ובמנהל הסיסמאות.

## מתקדם: הקמה ידנית עם wrangler

רק למי שלא רוצה להשתמש בהקמה האוטומטית. צריך Node.js (גרסת LTS מ-https://nodejs.org; בודקים עם `node --version`) ואת התיקייה `cloudflare` מהקוד של Klara Wisper (‏GitHub ← Code ← Download ZIP).

כל הפקודות רצות ב-Terminal, מתוך התיקייה `cloudflare`. כדי להיכנס אליה, כותבים `cd` ורווח, גוררים את התיקייה לחלון ה-Terminal ולוחצים Enter.

### 1. חשבון Cloudflare חינמי

נרשמים בחינם ב-https://dash.cloudflare.com/sign-up ומאשרים את המייל.

### 2. התחברות מה-Terminal

```
npx wrangler login
```

נפתח דפדפן, ובו מאשרים את הגישה (Allow). בפעם הראשונה `npx` שואל אם להתקין את wrangler, ועונים `y`.

### 3. יצירת מסד הנתונים

```
npx wrangler d1 create klara-wisper
```

בפלט מופיעה שורה כמו `database_id = "1234abcd-…"`. מעתיקים את הערך שבין המירכאות, ואז:

1. פותחים את הקובץ `wrangler.toml` שבתיקייה בעורך טקסט, למשל TextEdit.
2. מחליפים את `REPLACE_WITH_YOUR_D1_ID` בערך שהועתק. מחליפים רק את הטקסט שבין המירכאות, ולא נוגעים במירכאות עצמן.
3. שומרים את הקובץ.

אם wrangler שואל אם להוסיף את ההגדרה לקובץ בעצמו, עונים `n`. הקובץ כבר מוכן, ורק ה-id חסר בו.

### 4. יצירת הטבלאות

```
npx wrangler d1 execute klara-wisper --remote --file=schema.sql
```

אם מופיעה בקשת אישור, עונים `y`.

### 5. יצירת שלושת הטוקנים (המפתחות)

יש שלושה טוקנים, וכולם חייבים להיות שונים זה מזה:
- **טוקן העלאה** (`KLARA_TOKEN`): רק Klara Wisper במחשב משתמשת בו, כדי להעלות שיחות ולהוריד ולמחוק הקלטות מהטלפון. הוא לא יוצא מהמחשב.
- **טוקן קריאה** (`KLARA_MCP_TOKEN`): נכנס לכתובת של ה-connector ב-claude.ai. הוא מאפשר רק לקרוא. גם אם הכתובת דולפת, אי אפשר למחוק או לשנות איתו כלום.
- **טוקן הקלטה** (`KLARA_REC_TOKEN`): נכנס לקישור ההקלטה בטלפון. הוא מאפשר רק להעלות הקלטות, ולא לקרוא שום דבר.

יוצרים כל טוקן בנפרד. מריצים שלוש פעמים את הפקודה הזאת, ושומרים את שלוש התוצאות במקום בטוח (למשל במנהל סיסמאות):

```
openssl rand -hex 32
```

אחר כך מריצים, ומדביקים את טוקן ההעלאה:

```
npx wrangler secret put KLARA_TOKEN
```

ואז מריצים, ומדביקים את טוקן הקריאה:

```
npx wrangler secret put KLARA_MCP_TOKEN
```

ואז מריצים, ומדביקים את טוקן ההקלטה:

```
npx wrangler secret put KLARA_REC_TOKEN
```

כשמתבקשים, מדביקים ולוחצים Enter. אם wrangler שואל אם ליצור Worker חדש בשם `klara-wisper-gateway`, עונים `y`.

כל טוקן חייב להיות באורך 32 תווים לפחות. עם טוקן קצר יותר ה-Worker מסרב לכל בקשה שמשתמשת בו, וכששני טוקנים זהים, ה-connector או קישור ההקלטה לא עובדים.

### 6. העלאה לאוויר

```
npx wrangler deploy
```

בסוף הפלט מופיעה כתובת כמו `https://klara-wisper-gateway.<subdomain>.workers.dev`. זו כתובת ה-Worker. בפעם הראשונה Cloudflare עשויה לבקש לבחור שם לתת-הדומיין של workers.dev.

כדי לבדוק שהכול עובד, פותחים בדפדפן את הכתובת ומוסיפים בסופה `/api/health`. אמור להופיע `{"ok":true,"version":"1.1.0",…}`, ובסוף `"recordings"`.

### 7. חיבור ל-Klara Wisper

**הגדרות** ← **ענן** ← **"הגדרה ידנית"**: מדביקים את כתובת ה-Worker, את טוקן ההעלאה ואת טוקן ההקלטה. האפליקציה בודקת שה-Worker עונה, שומרת את הטוקנים מוצפנים ומציגה את כתובת ה-connector ואת קישור ההקלטה. קישור ההקלטה הוא `https://klara-wisper-gateway.<subdomain>.workers.dev/rec/<טוקן ההקלטה>`.

Worker שהוקם לפני שהיה קישור הקלטה מתעדכן כשמריצים שוב `npx wrangler deploy`: הטבלאות של ההקלטות נוצרות לבד בשימוש הראשון. צריך רק להוסיף את `KLARA_REC_TOKEN`.
