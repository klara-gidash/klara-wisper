# סנכרון ל-Cloudflare: לשאול את Claude על שיחות גם מהטלפון

## מה זה עושה

בדרך כלל Klara Wisper שומרת הכול על המחשב, ו-Claude קורא את השיחות דרך חיבור מקומי. החיבור הזה עובד רק ב-Claude Desktop וב-Claude Code על אותו מק, ולכן Claude בטלפון לא מגיע אליו.

סנכרון ל-Cloudflare הוא תוספת רשות, והוא כבוי עד שמפעילים אותו. אחרי שמפעילים אותו:

- Klara Wisper מעלה **רק את התמלולים והסיכומים** (טקסט). **האודיו לא עולה אף פעם**, והוא נשאר רק על המחשב.
- ההעלאה היא **לחשבון Cloudflare פרטי**: מסד נתונים קטן ושרת קטן (Worker) שמקימים פעם אחת. אין שרת משותף, ואין צד אחר שמנהל אותו.
- ב-claude.ai מוסיפים את ה-Worker בתור connector, ומאותו רגע אפשר לשאול את Claude על השיחות גם מאפליקציית Claude בטלפון.
- Claude יכול רק לקרוא. דרך החיבור הזה הוא לא יכול לשנות או למחוק שום דבר.
- יש שני טוקנים (מפתחות): **טוקן העלאה**, שנשאר רק במחשב ואיתו Klara Wisper מעלה ומוחקת שיחות, ו**טוקן קריאה**, שנכנס לכתובת של ה-connector ב-claude.ai ומאפשר רק לקרוא.

## לפני שמתחילים: מה מוותרים עליו בפרטיות

- **בלי הסנכרון**, התמלולים נמצאים רק על המחשב. **עם הסנכרון**, עותק שלהם נשמר גם בענן, בחשבון ה-Cloudflare הפרטי. Cloudflare מצפינה את המידע בשמירה, אבל הוא בכל זאת נמצא אצל ספק ענן.
- **הכתובת של ה-connector כוללת את טוקן הקריאה.** עם הכתובת הזאת אפשר לקרוא את כל השיחות, בלי שום סיסמה נוספת, אבל אי אפשר להעלות, לשנות או למחוק. פרטים באזהרה בסוף המסמך.
- בשיחות מדברים גם אנשים אחרים. לפני שמעלים שיחות עבודה לענן, כדאי לוודא שזה מתאים למדיניות של החברה ולמה שסוכם עם המשתתפים.
- כש-Claude קורא שיחה, התוכן עובר ל-Anthropic, בדיוק כמו בחיבור המקומי.
- אפשר להפסיק בכל רגע: מכבים את הסנכרון ומוחקים את המידע (ההסבר בהמשך).

## מה צריך

- חשבון Cloudflare. התוכנית החינמית מספיקה לשימוש אישי.
- Node.js, בשביל הפקודה `npx`. כדי לבדוק אם הוא מותקן, מריצים ב-Terminal את `node --version`. אם לא מופיע מספר גרסה, מתקינים את גרסת ה-LTS מ-https://nodejs.org.
- התיקייה `cloudflare` מהקוד של Klara Wisper. מורידים אותה מהריפו ב-GitHub (‏Code ← Download ZIP).
- חשבון ב-claude.ai, ואפליקציית Claude בטלפון.

## הקמה, צעד אחר צעד

כל הפקודות רצות ב-Terminal, מתוך התיקייה `cloudflare`. כדי להיכנס אליה, כותבים `cd` ורווח, גוררים את התיקייה לחלון ה-Terminal ולוחצים Enter.

### 1. חשבון Cloudflare חינמי

נרשמים בחינם ב-https://dash.cloudflare.com/sign-up ומאשרים את המייל.

### 2. התחברות מה-Terminal

```
npx wrangler login
```

נפתח דפדפן, ובו מאשרים את הגישה (Allow). בפעם הראשונה `npx` שואל אם להתקין את wrangler, ועונים `y`.

### 3. יצירת מסד הנתונים

```
npx wrangler d1 create klara-wisper
```

בפלט מופיעה שורה כמו `database_id = "1234abcd-…"`. מעתיקים את הערך שבין המירכאות, ואז:

1. פותחים את הקובץ `wrangler.toml` שבתיקייה בעורך טקסט, למשל TextEdit.
2. מחליפים את `REPLACE_WITH_YOUR_D1_ID` בערך שהועתק. מחליפים רק את הטקסט שבין המירכאות, ולא נוגעים במירכאות עצמן.
3. שומרים את הקובץ.

אם wrangler שואל אם להוסיף את ההגדרה לקובץ בעצמו, עונים `n`. הקובץ כבר מוכן, ורק ה-id חסר בו.

### 4. יצירת הטבלה

```
npx wrangler d1 execute klara-wisper --remote --file=schema.sql
```

אם מופיעה בקשת אישור, עונים `y`.

### 5. יצירת שני הטוקנים (המפתחות)

יש שני טוקנים, וחייבים להיות שונים זה מזה:
- **טוקן העלאה** (`KLARA_TOKEN`): רק Klara Wisper במק משתמשת בו, כדי להעלות שיחות. הוא לא יוצא מהמחשב.
- **טוקן קריאה** (`KLARA_MCP_TOKEN`): נכנס לכתובת של ה-connector ב-claude.ai. הוא מאפשר רק לקרוא. גם אם הכתובת דולפת, אי אפשר למחוק או לשנות איתו כלום.

יוצרים כל טוקן בנפרד. מריצים פעמיים את הפקודה הזאת, ושומרים את שתי התוצאות במקום בטוח (למשל במנהל סיסמאות):

```
openssl rand -hex 32
```

אחר כך מריצים, ומדביקים את טוקן ההעלאה:

```
npx wrangler secret put KLARA_TOKEN
```

ואז מריצים, ומדביקים את טוקן הקריאה:

```
npx wrangler secret put KLARA_MCP_TOKEN
```

כשמתבקשים, מדביקים ולוחצים Enter. אם wrangler שואל אם ליצור Worker חדש בשם `klara-wisper-gateway`, עונים `y`.

כל טוקן חייב להיות באורך 32 תווים לפחות. עם טוקן קצר יותר ה-Worker מסרב לכל בקשה שמשתמשת בו, וכששני הטוקנים זהים ה-connector לא עובד.

### 6. העלאה לאוויר

```
npx wrangler deploy
```

בסוף הפלט מופיעה כתובת כמו `https://klara-wisper-gateway.<subdomain>.workers.dev`. זו כתובת ה-Worker. בפעם הראשונה Cloudflare עשויה לבקש לבחור שם לתת-הדומיין של workers.dev.

כדי לבדוק שהכול עובד, פותחים בדפדפן את הכתובת ומוסיפים בסופה `/api/health`. אמור להופיע `{"ok":true,…}`.

## ב-Klara Wisper

1. **הגדרות** ← **"Claude מהטלפון (Cloudflare, רשות)"**.
2. מדביקים את כתובת ה-Worker ואת **טוקן ההעלאה** (לא את טוקן הקריאה), ולוחצים **"הפעלה"**. האפליקציה בודקת שה-Worker עונה ומקבל את הטוקן. טוקן ההעלאה נשמר מוצפן ב-Keychain של macOS, ולא בקובץ ההגדרות. הוא נשלח רק ל-Worker עצמו, ולא יוצא מהמחשב לשום מקום אחר.
3. לוחצים **"סנכרון כל השיחות"** כדי להעלות את השיחות שכבר נשמרו.
4. מכאן כל שיחה עולה לבד אחרי שהיא נשמרת, ושוב בכל פעם שהיא מתעדכנת: כשנוסף סיכום, כשנקבע שם או כשמשתתף מזוהה.

## ב-claude.ai

1. נכנסים ל-claude.ai בדפדפן במחשב ← **Settings** ← **Connectors** ← **Add custom connector**.
2. בשם כותבים `Klara Wisper`, ובכתובת מזינים:

   ```
   https://klara-wisper-gateway.<subdomain>.workers.dev/mcp/<TOKEN>
   ```

   במקום `<TOKEN>` מדביקים את **טוקן הקריאה** (`KLARA_MCP_TOKEN`) מצעד 5, ולא את טוקן ההעלאה. את ההגדרות המתקדמות (OAuth) משאירים ריקות.
3. לוחצים **Add**.
4. מאותו רגע ה-connector זמין גם באפליקציית Claude בטלפון, באותו חשבון. אם Claude לא משתמש בו, בודקים שהוא מופעל בתפריט הכלים של השיחה.

**חשבון ארגוני (Team או Enterprise):** ייתכן שרק חשבונות עם הרשאת ניהול יכולים להוסיף connector מותאם. connector שמוסיפים ברמת הארגון זמין לכל החשבונות בארגון, וטוקן הקריאה נמצא בתוך הכתובת. לכן כל חשבון בארגון שיחובר אליו יוכל לקרוא את השיחות. **לא מבקשים מצוות הניהול להוסיף את ה-connector לארגון.** במקום זה משתמשים בחשבון Claude אישי, או מתייעצים קודם עם צוות ה-IT.

## החלפת הטוקן

כדאי להחליף טוקן אם יש חשש שהוא דלף, וגם סתם מדי פעם. ב-Klara Wisper צריך לעדכן רק את טוקן ההעלאה: האפליקציה לא משתמשת בטוקן הקריאה.

**אם כתובת ה-connector דלפה** (טוקן הקריאה):
1. מריצים `openssl rand -hex 32` ושומרים את הטוקן החדש.
2. מריצים `npx wrangler secret put KLARA_MCP_TOKEN` ומדביקים אותו. מהרגע הזה הכתובת הישנה מפסיקה לעבוד.
3. ב-claude.ai מסירים את ה-connector הישן ומוסיפים אותו מחדש עם הכתובת החדשה.

**אם טוקן ההעלאה דלף:**
1. מריצים `openssl rand -hex 32` ושומרים את הטוקן החדש.
2. מריצים `npx wrangler secret put KLARA_TOKEN` ומדביקים אותו.
3. ב-Klara Wisper, בהגדרות "Claude מהטלפון (Cloudflare, רשות)", מעדכנים את הטוקן.

## מחיקת כל המידע

קודם מכבים את הסנכרון ב-Klara Wisper, כדי שהשיחות לא יעלו שוב.

**כדי לרוקן את מסד הנתונים ולהשאיר את ה-Worker**, מריצים (עם הכתובת האמיתית ועם טוקן ההעלאה):

```
curl -X DELETE https://klara-wisper-gateway.<subdomain>.workers.dev/api/meetings \
  -H "Authorization: Bearer <UPLOAD_TOKEN>" -H "Content-Type: application/json" -d '{"all":true}'
```

התשובה היא `{"ok":true,"deleted":…}` עם מספר השיחות שנמחקו.

**כדי למחוק הכול לגמרי**, מריצים מתוך התיקייה `cloudflare`:

```
npx wrangler delete
npx wrangler d1 delete klara-wisper
```

בסוף מסירים את ה-connector מ-claude.ai.

## אזהרה: אסור לשתף את הכתובת

טוקן הקריאה נמצא בתוך הכתובת של ה-connector, ועם הכתובת הזאת **אפשר לקרוא את כל השיחות**, בלי שום סיסמה נוספת (אבל לא להעלות, לשנות או למחוק). לכן:

- לא שולחים אותה בצ'אט או במייל.
- לא מציגים אותה בשיתוף מסך.
- לא שומרים אותה במסמך משותף.

אם הכתובת דלפה, מחליפים את טוקן הקריאה מיד (הסבר בסעיף "החלפת הטוקן").

את טוקן ההעלאה לא מכניסים לשום כתובת ולא משתפים בכלל. הוא נשמר רק ב-Klara Wisper ובמנהל הסיסמאות.
