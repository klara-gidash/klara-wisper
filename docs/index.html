התקנה

  1. להוריד

    בעמוד ה-Releases מורידים את Klara Wisper.dmg. צריך מק עם שבב Apple (M1 ומעלה), macOS 14.4 ומעלה, ובערך 4GB פנויים.

  2. לגרור ל-Applications ולפתוח

    בפתיחה הראשונה macOS חוסם את האפליקציה כי היא לא חתומה אצל Apple. פותחים את הגדרות המערכת ← פרטיות ואבטחה ← "לפתוח בכל זאת". צריך לעשות את זה פעם אחת.

  3. ההקמה הראשונה

    האפליקציה מתקינה לבד את מנוע התמלול ומורידה את המודלים (כ-2.4GB, עם פס התקדמות). אין צורך בהרשאות מנהל.

  4. הרשאות

    מיקרופון, קול המחשב, נגישות (להדבקת הכתבה), ניטור מקלדת (מקש fn), יומן, ואוטומציה לדפדפן (לזיהוי Meet ו-Teams בלשונית). מסך ההקמה מבקש את כולן.

  5. היומן של Google

    מוסיפים את חשבון ה-Google ב"הגדרות המערכת ← חשבונות אינטרנט". מכאן כל שיחה מקבלת את השם ואת המשתתפים מהאירוע ביומן.

כל הפרטים, כולל פתרון בעיות והסרה: מדריך ההתקנה.

חיבור ל-Claude

האפליקציה מחברת את עצמה ל-Claude Desktop ול-Claude Code (שרת MCP בשם klara-wisper), ומתקינה את ארבעת הסקילים ל-Claude Code. אחרי ההתקנה צריך לסגור ולפתוח את Claude Desktop פעם אחת.

לסיכום האוטומטי צריך עוד צעד חד-פעמי: בהגדרות ← Claude לוחצים על "התחברות ל-Claude". נפתח חלון Terminal, ואחריו דף התחברות בדפדפן עם החשבון הרגיל. אין צורך במפתח API.

לסיכום יומי כל ערב: ב-Claude Desktop יוצרים משימה מתוזמנת (Scheduled task) שרצה כל יום, למשל ב-19:00, עם הבקשה:

סיכום יומי של השיחות של היום

המשימה רצה על המק, ולכן הוא צריך להיות דלוק בשעה הזאת.

ב-Claude Desktop מעלים את הסקילים ידנית: הגדרות ← Capabilities ← Upload skill, קובץ zip לכל תיקייה מהמאגר klara-wisper-skills.

פרטיות

  • ההקלטה, התמלול וזיהוי הדוברים רצים על המק. האודיו לא יוצא ממנו.
  • Claude מקבל את הטקסט של השיחות רק כשפונים אליו, ובסיכום האוטומטי אם הוא מופעל.
  • תוכן השיחות מוגדר אצל Claude כ"מידע, לא הוראות": הוא לא שולח מייל ולא מבצע פעולה רק כי מישהו ביקש את זה בשיחה.
  • מייל יוצא רק כשמבקשים, קודם כטיוטה, ורק אחרי אישור מפורש.
  • המחבר לטלפון אופציונלי, ורץ בחשבון Cloudflare פרטי.
