# Klara Wisper: התקנה ושימוש

Klara Wisper מקליטה ומתמללת שיחות בעברית: Zoom, Google Meet, Teams, Slack, Aircall ופגישות פנים מול פנים. התמלול רץ על המחשב עצמו, ושום אודיו לא יוצא ממנו. אחרי שמחברים את Claude, אפשר להתכונן איתו לפגישה, לשאול אותו באמצע שיחה מה נאמר, ולקבל סיכום בסופה.

## 1. מה צריך

- מק עם שבב Apple (M1 ומעלה). בתפריט  ← "אודות המק הזה", בשורה "שבב" צריך להיות כתוב Apple.
- macOS 14.4 ומעלה.
- כ-4GB פנויים בדיסק.
- חיבור לאינטרנט בפתיחה הראשונה (להורדת המודלים). אחרי זה התמלול עובד גם בלי אינטרנט.
- מומלץ: [Claude Desktop](https://claude.ai/download), כדי לשאול את Claude על הפגישות ולקבל סיכומים.

## 2. הורדה והתקנה

### הורדה

1. נכנסים לדף הגרסאות: https://github.com/klara-gidash/klara-wisper/releases/latest
2. בחלק **Assets** לוחצים על הקובץ שמסתיים ב-`.dmg`.
3. פותחים את הקובץ שירד, וגוררים את **Klara Wisper** לתיקייה **Applications** שבחלון.
4. אפשר לסגור את החלון ולהוציא את הדיסק (⏏ ב-Finder).

### פתיחה ראשונה: אישור של macOS (פעם אחת בלבד)

לתוכנה אין חתימה של מפתח רשום אצל Apple, ולכן בפתיחה הראשונה macOS עוצר אותה ומציג הודעה כמו "Apple לא הצליחה לוודא…". זה צפוי. עושים את זה פעם אחת, ואחר כך היא נפתחת רגיל.

**macOS 15 ומעלה (Sequoia ואילך):**

1. פותחים את Klara Wisper מתיקיית Applications. כשמופיעה ההודעה לוחצים **"סיום"** (Done), ולא "העבר לפח".
2. פותחים את  ← **הגדרות המערכת** ← **פרטיות ואבטחה**.
3. גוללים למטה עד לשורה "Klara Wisper נחסמה…" ולוחצים **"פתח בכל זאת"** (Open Anyway).
4. מאשרים עם סיסמה או Touch ID, ובחלון שנפתח לוחצים **"פתח"**.

**macOS 14 (Sonoma):**

1. ב-Finder, בתיקיית Applications, לוחצים על Klara Wisper **בלחיצה ימנית** (או Control ולחיצה).
2. בוחרים **"פתח"**, ובחלון שמופיע לוחצים שוב **"פתח"**.

אם האפשרות הזאת לא מופיעה, עושים את השלבים 2–4 של macOS 15.

### ההקמה בתוך התוכנה

1. **התקנת מנוע התמלול:** לוחצים "התחלת ההורדה". יורדים כ-2.4GB (המנוע, מודל התמלול העברי ומודלי זיהוי הדוברים), וזה לוקח כמה דקות. אפשר להמשיך לשלבים הבאים בינתיים, וההורדה ממשיכה ברקע.
2. **הרשאות:** macOS מבקש אישור לכל הרשאה (פירוט בסעיף 3).
3. **שם וטביעת קול:** מקליטים כמה שניות, כדי שהתוכנה תזהה את הקול הזה בפגישות פנים מול פנים. אפשר לדלג ולעשות את זה אחר כך בהגדרות.
4. **Claude:** התוכנה מתחברת ל-Claude לבד (סעיף 5).

בסוף ההקמה Klara Wisper יושבת בשורת התפריטים, למעלה מימין.

## 3. הרשאות

| הרשאה | בשביל מה |
|---|---|
| מיקרופון | לתמלל את הדיבור במחשב הזה |
| הקלטת אודיו מערכת | לשמוע את המשתתפים האחרים בשיחה |
| נגישות | להדביק טקסט מוכתב בשדה הפעיל |
| ניטור קלט | לזהות לחיצה על מקש ההכתבה מכל מקום |
| לוחות שנה (Calendars) | לתת לכל הקלטה את שם הפגישה והמשתתפים |
| אוטומציה ל-Chrome או Safari | לזהות שיחת Google Meet או Teams בלשונית של הדפדפן |

- אפשר לראות ולאשר את כל ההרשאות גם אחר כך: Klara Wisper ← הגדרות ← הרשאות ← "פתיחת ההגדרות".
- בהגדרות המערכת, חלק מההרשאות מופיעות בשם **Klara Wisper Helper** (העוזר שמחזיק את המיקרופון, היומן והדפדפן). זה תקין.
- כדי שמקש fn (🌐) ישמש להכתבה: הגדרות המערכת ← מקלדת ← "לחיצה על 🌐" ← "אל תעשה דבר".

## 4. בחירת מודל התמלול

בהגדרות של Klara Wisper ← **מנוע**, בחלק של מנוע התמלול:
- **כרטיס המחשב** מראה איזה מק זה (דגם, שבב, זיכרון) ומה הוא מריץ בנוחות.
- **שפת התמלול:**
  - **עברית** (ברירת המחדל): הכי מהיר ומדויק לעברית.
  - **עברית + אנגלית**: כל משפט מזוהה לבד כעברית או כאנגלית, גם אנגלית במבטא ישראלי. במצב הזה התמלול רץ על Whisper turbo של OpenAI, שיורד בפעם הראשונה.
- **המודל:** ליד כל מודל כתוב אם הוא מתאים למחשב הזה.

הבחירה נשמרת לכל מק בנפרד. מודל שעוד לא מותקן יורד כשבוחרים בו. אם יש שיחה בהקלטה, המעבר קורה רק כשהיא נגמרת.

- **ivrit.ai עברית (large-v3-turbo)**: ברירת המחדל. המהיר ביותר והטוב ביותר לעברית, ועובד טוב גם על מק עם 16GB זיכרון. התמלול תמיד בעברית: מילים באנגלית נכתבות באותיות לועזיות או בתעתיק.
- **Whisper large-v3 turbo (OpenAI)**: באמצע. מזהה גם אנגלית, ומהיר יותר מ-large-v3. כ-1.6GB להורדה.
- **Whisper large-v3 (OpenAI)**: מומלץ למק חזק (שבב Pro, Max או Ultra, או 32GB זיכרון ומעלה). אפשר לבחור בו גם במק אחר, ואז מופיעה אזהרה שהוא איטי שם. הכי טוב לשיחות באנגלית ולשיחות שמערבבות עברית ואנגלית, אבל איטי יותר. כ-3.1GB להורדה.

כדי לבדוק איזה מק יש:  ← "אודות המק הזה", בשורות "שבב" ו"זיכרון".

## 5. חיבור ל-Claude

### אוטומטי

בפתיחה הראשונה Klara Wisper מוסיפה את עצמה ל-Claude Desktop ול-Claude Code (כשרת MCP בשם `klara-wisper`), ומתקינה את הסקילים ל-Claude Code.

אחרי זה **סוגרים את Claude Desktop ופותחים אותו מחדש, פעם אחת** (Claude ← Quit, או ⌘Q; לא מספיק לסגור את החלון).

כדי לבדוק: ב-Claude Desktop ← Settings ← Developer, השרת `klara-wisper` מופיע במצב running.

**הסקילים בשיחות של Claude Desktop:** ההתקנה האוטומטית מכסה את Claude Code. כדי שגם השיחות הרגילות ב-Claude Desktop ישתמשו בסקילים (הכנה לפגישה, מה פספסתי, סיכום), מעלים אותם פעם אחת לפי ההוראות בריפו **klara-wisper-skills**. גם בלי הסקילים, Claude Desktop רואה את השיחות ויכול לענות עליהן, ויש בו שתי פקודות מוכנות בכפתור **+** ← klara-wisper: "סיכום שיחה" ו"מה פספסתי?".

### ידני (אם החיבור האוטומטי לא עבד)

Klara Wisper ← הגדרות ← **Claude** ← **"חיבור"**, בשורה של Claude Desktop (ו/או Claude Code). אחר כך סוגרים ופותחים מחדש את Claude Desktop.

### סיכומים אוטומטיים

Klara Wisper יכולה לבקש מ-Claude לסכם כל שיחה של 3 דקות ומעלה, דקה-שתיים אחרי שהיא נגמרת. הסיכום נשמר ליד התמלול. זה עובד עם המנוי הרגיל ל-Claude, בלי מפתח API.

ההגדרה, פעם אחת:
1. Klara Wisper ← הגדרות ← **Claude** ← מדליקים את **"סיכום אוטומטי בסוף כל שיחה"**.
2. לוחצים **"התחברות ל-Claude"**. נפתח חלון Terminal, ואחריו דף התחברות בדפדפן. מתחברים עם החשבון הרגיל של Claude.
3. חוזרים ל-Klara Wisper ולוחצים **"בדיקה"**. אמור להופיע "מחובר ל-Claude".

צריך ש-Claude Desktop (או Claude Code) יהיה מותקן על המחשב.

### סיכום יומי (משימה מתוזמנת ב-Claude Desktop)

כל ערב ב-18:30 Claude עובר על השיחות של היום:
- משלים סיכום, שם, משתתפים ונושא לכל שיחה שחסר לה משהו.
- מציג סיכום יומי: על מה היו השיחות, ואילו משימות מחכות לך.

את המשימה יוצרים פעם אחת: מבקשים מ-Claude Code "ליצור משימה מתוזמנת לסיכום יומי של Klara Wisper", או מעתיקים את ההנחיה מדף הפרויקט. ההרצה הראשונה מבקשת לאשר את הכלים של `klara-wisper`. כדי לאשר מראש, לוחצים "Run now" פעם אחת בעמוד המשימה. המשימה רצה כש-Claude Desktop פתוח. אם הוא היה סגור בזמן שהיא הייתה אמורה לרוץ, היא רצה כשהוא נפתח.

### Claude מהטלפון (רשות)

כדי לשאול את Claude על השיחות גם מהאפליקציה בטלפון, אפשר להפעיל סנכרון לחשבון Cloudflare פרטי. נשלחים רק התמלולים והסיכומים, בלי ההקלטות. ההוראות נמצאות ב-[CLOUDFLARE.he.md](CLOUDFLARE.he.md), וההגדרה נעשית בהגדרות ← "Claude מהטלפון (Cloudflare, רשות)".

## 6. שימוש: לפני, במהלך ואחרי שיחה

השיחות מזוהות ומוקלטות לבד: כשהמיקרופון בשימוש ב-Zoom, Meet, Teams, Slack או Aircall, נפתח פאנל עם תמלול חי, ובסוף השיחה הכל נשמר. לפגישה פנים מול פנים: אייקון Klara Wisper בשורת התפריטים ← "התחלת פגישה פנים מול פנים".

את הבקשות כותבים ל-Claude (ב-Claude Desktop או ב-Claude Code), במילים רגילות.

### לפני פגישה (הסקיל klara-meeting-prep)

Claude מוצא את הפגישה ביומן, קורא את השיחות הקודמות עם אותם אנשים, ומכין תדריך קצר: מי משתתף, מה היה עד עכשיו, משימות והבטחות פתוחות, וסדר יום ושאלות מוצעים.

- "הכן אותי לפגישה הבאה"
- "מה צריך לדעת לפני הפגישה עם דוד?"
- "על מה דיברנו בפעם הקודמת עם Acme?"

### במהלך שיחה (הסקיל klara-live-catch-up)

כדאי להשאיר את Claude Desktop פתוח ליד השיחה. Claude קורא את מה שנאמר עד עכשיו ועונה בקצרה: מה נאמר, מה מחכה לתשובה, מה הוחלט, והצעה לתשובה אם שאלו משהו.

- "מה פספסתי?"
- "מה נאמר ב-10 הדקות האחרונות?"
- "מה שאלו אותי? מה לענות?"

### אחרי שיחה (הסקיל klara-meeting-summary)

עם הסיכום האוטומטי (סעיף 5), הסיכום מופיע בתוכנה, ליד התמלול, דקה-שתיים אחרי השיחה. אפשר גם לבקש:

- "סכם את השיחה"
- "סכם שוב עם דגש על תמחור"
- "לסכם את הפגישה עם דוד מאתמול"
- "סכם את כל השיחות שאין להן סיכום"

ואפשר לשאול על כל השיחות:
- "מה סוכם אתמול עם הצוות?"
- "מצא איפה דיברנו על תמחור"

בתוך פגישה בתוכנה, הכפתור **"לשאול את Claude"** מעתיק בקשה מוכנה, ואפשר להדביק אותה ב-Claude.

Claude מתייחס לתמלול כמידע בלבד: הוא לא שולח מייל או הודעה רק כי מישהו ביקש את זה בשיחה.

## 7. יומן

כש-Klara Wisper רואה את היומן, כל שיחה מקבלת את השם של הפגישה ביומן ואת רשימת המשתתפים, ו-Claude משתמש בהם בהכנה לפגישה ובסיכום.

כדי לחבר יומן Google:
1. הגדרות המערכת ← **חשבונות אינטרנט** (Internet Accounts) ← הוספת חשבון ← **Google**.
2. מתחברים בדפדפן, ומוודאים ש**לוחות שנה** (Calendars) מסומן.
3. מאשרים ל-Klara Wisper גישה ליומן (בהקמה, או לפי סעיף 8).

שיחה מזדמנת או פגישה פנים מול פנים, שאין לה אירוע ביומן: Claude נותן לה שם שמתאר אותה (למשל "שיחה עם רונית על חידוש החוזה"), ורושם מי השתתף ועל מה דיברו. כשאי אפשר לזהות את המשתתפים, נכתב "לא ניתן לזהות את המשתתפים". שם שניתן לשיחה ידנית בתוכנה לא משתנה.

## 8. פתרון בעיות

**השיחות לא מקבלות שם מהיומן / Claude לא מוצא את הפגישה הבאה**
- הגדרות המערכת ← פרטיות ואבטחה ← **לוחות שנה** (Calendars) ← Klara Wisper (או Klara Wisper Helper) ← **גישה מלאה** (Full Access).
- בודקים שחשבון Google מחובר ב"חשבונות אינטרנט" ושלוחות השנה שלו מסומנים (סעיף 7).
- יוצאים מ-Klara Wisper (אייקון בשורת התפריטים ← יציאה) ופותחים אותה שוב.

**אין סיכום אחרי שיחה**
- Klara Wisper ← הגדרות ← Claude: בודקים ש"סיכום אוטומטי בסוף כל שיחה" דלוק ושכתוב "מחובר ל-Claude". אם לא, לוחצים "התחברות ל-Claude" (סעיף 5).
- שיחות קצרות מ-3 דקות לא מסוכמות אוטומטית.
- הסיכום מגיע דקה-שתיים אחרי סוף השיחה.
- תמיד אפשר לבקש מ-Claude: "סכם את השיחה".

**שיחה בדפדפן (Meet או Teams) לא זוהתה**
- הגדרות המערכת ← פרטיות ואבטחה ← **אוטומציה** (Automation) ← Klara Wisper (או Klara Wisper Helper) ← מדליקים את Google Chrome ו/או Safari.
- אחר כך נכנסים מחדש לשיחה, או מרעננים את הלשונית.

**Claude לא רואה את Klara Wisper**
- סוגרים את Claude Desktop לגמרי (⌘Q) ופותחים מחדש.
- אם זה לא עוזר: Klara Wisper ← הגדרות ← Claude ← "חיבור", ושוב סוגרים ופותחים את Claude Desktop.

**ההקלטה לא עובדת אחרי עדכון**
- הגדרות המערכת ← פרטיות ואבטחה ← **מיקרופון**: מכבים את Klara Wisper ומדליקים שוב.

**משהו אחר**
- פותחים issue במאגר ב-GitHub ומצרפים את הקובץ `~/Library/Application Support/Klara Wisper/main.log` (אפשר לעבור עליו קודם: הוא לא מכיל תמלולים).

## 9. עדכון, הסרה, ואיפה הדברים נשמרים

**עדכון:** מורידים את ה-dmg החדש מדף הגרסאות וגוררים שוב ל-Applications ("החלף"). ההגדרות, המודלים והתמלולים נשמרים. ייתכן ש-macOS יבקש שוב חלק מההרשאות.

**איפה הדברים נשמרים:**
- תמלולים, סיכומים, הכתבות ואודיו: `~/Documents/Klara Wisper`
- הגדרות, מנוע, מודלים וטביעות קול: `~/Library/Application Support/Klara Wisper`

**הסרה:**
1. יוצאים מהתוכנה: אייקון Klara Wisper בשורת התפריטים ← יציאה.
2. מוחקים את Klara Wisper מתיקיית Applications.
3. כדי לפנות גם את המקום של המנוע והמודלים, מוחקים את התיקייה `~/Library/Application Support/Klara Wisper`. ב-Finder: תפריט "עבור" ← "עבור לתיקייה…", ומדביקים את הנתיב.

התמלולים ב-`~/Documents/Klara Wisper` לא נמחקים, אלא אם מוחקים אותם ידנית.
