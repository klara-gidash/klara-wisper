# Klara Wisper

תמלול פגישות והכתבה, בעברית ובאנגלית, מקומית על המק. מה ש-Granola ו-Wispr Flow עושים, בכלי אחד.

- **הכתבה, בשלוש דרכים:**
  - בכל אפליקציה: `⌃⌥Space` מתחיל, ולחיצה נוספת מסיימת ומדביקה.
  - מחזיקים `fn` (🌐), מדברים ומשחררים. לחיצה כפולה מפעילה מצב ללא ידיים, ו-Esc מבטל.
  - כפתור המיקרופון באפליקציה: הטקסט מועתק ללוח ונשמר ברשימת ההכתבות.
- **שיחות אונליין:** Zoom, Google Meet, Teams ו-Slack Huddle, גם מהדסקטופ וגם מהדפדפן. התוכנה מזהה אותן לבד, פותחת פאנל עם תמלול חי, ושומרת הכל בסוף השיחה.
- **פנים מול פנים:** מיקרופון אחד, וזיהוי של כל דובר (עד 8). את מזוהה אוטומטית לפי טביעת הקול שלך.
- **Claude:** שואלים את Claude על הפגישות ("מה סוכם אתמול?"). לפני שיחה הוא מכין תדריך, במהלכה עונה על "מה פספסתי?", ואחריה מסכם.
- **סיכום אוטומטי:** דקה-שתיים אחרי כל שיחה של 3 דקות ומעלה, Claude כותב סיכום ושומר אותו ליד התמלול. שיחה שאין לה אירוע ביומן (שיחה מזדמנת או פנים מול פנים) מקבלת ממנו גם שם, משתתפים ונושא.
- **היומן:** כל שיחה מותאמת לאירוע ביומן, כולל שיחות ישנות, ומקבלת את השם והמשתתפים שלו.

## מודלים (הכל רץ מקומית)

**בחירת מודל התמלול:** בהגדרות > מנוע. ברירת המחדל היא ivrit.ai turbo, שהוא המהיר ביותר והטוב ביותר בעברית, ומתאים גם למק עם 16GB. במק חזק (שבב Pro, Max או Ultra, או 32GB ומעלה) אפשר לבחור את Whisper large-v3 של OpenAI, שעדיף לאנגלית ולשיחות מעורבות. יש גם אפשרות ביניים: OpenAI large-v3 turbo.
- מודל שעוד לא מותקן יורד כשבוחרים בו.
- המנוע עובר למודל החדש רק כשאין שיחה בהקלטה או בעיבוד.

| תפקיד | מודל |
|---|---|
| תמלול | **ivrit.ai Whisper large-v3 turbo** (MLX). מודל עברי: בערך חצי משגיאות העברית של OpenAI large-v3, ומהיר פי כמה. התמלול תמיד בעברית; מילים באנגלית נכתבות באותיות לועזיות או בתעתיק. |
| זיהוי דוברים | **NVIDIA Nemotron-3-Diarization** וטביעות קול (SpeechBrain ECAPA). רץ אחרי השיחה, ולא בזמן אמת. |
| זיהוי דיבור | Silero VAD |

**איך זה מהיר:**
- משפטים קצרים רצופים של אותו צד נארזים לקריאה אחת ל-Whisper (עד ~24 שניות). כל קריאה עולה מעבר מלא של 30 שניות במקודד, אז פחות קריאות = הרבה פחות זמן.
- כל משפט עובר במקודד פעם אחת בלבד.
- קטעים קצרים מחצי שנייה, או שקטים מאוד, לא נשלחים לתמלול.

**בסוף שיחה:**
1. התמלול נשמר מיד.
2. ההקלטה מתפנה לשיחה הבאה.
3. ברקע, בתור:
   - הגרסה המלאה מוחלפת.
   - נוצר קובץ האודיו.
   - שלב הדוברים מוסיף מי אמר מה, וחותך משפטים שבהם התחלף דובר.

**שלב הדוברים:** דובר עם פחות מ-20 שניות דיבור מצורף לקרוב ביותר אליו, ושני דוברים עם קול דומה מאוחדים. כך שיעול או משפט רועש לא הופכים ל"משתתף" חדש.

התיקייה היא מקור האמת. אם אינדקס החיפוש נמחק, הוא נבנה מחדש מהקבצים.

## התקנה

התקנה על מק חדש (Apple Silicon, macOS 14.4 ומעלה, עם Command Line Tools): `bash scripts/setup.sh`.

הסקריפט:
- מתקין את Node ו-uv לתוך `~/.local`, בלי sudo.
- מתקין את המנוע ומוריד כ-5GB של מודלים.
- בונה את העוזר של macOS ומתקין את `Klara Wisper.app` לתוך `/Applications`.

בנייה מחדש אחרי שינוי בקוד: `bash scripts/dist.sh`.

### התקנה לעמיתים (קובץ dmg)

`bash scripts/make-dmg.sh` בונה את `release/Klara Wisper.dmg` (כ-160MB). הבנייה לא נוגעת באפליקציה המותקנת.

- האפליקציה עצמאית לגמרי, ולא תלויה בתיקייה הזאת. בתוכה נמצאים:
  - `uv` בגרסה נעולה, שנבדק מול SHA-256.
  - קוד המנוע ו-`uv.lock`.
- בפתיחה הראשונה מסך ההקמה:
  - מתקין את Python 3.12 ואת החבילות הנעולות לתוך `~/Library/Application Support/Klara Wisper/engine` (כ-1.3GB, בלי הרשאות מנהל).
  - מוריד את שלושת המודלים (כ-2.1GB), עם פס התקדמות.
- השרת של Claude (MCP) רץ מאותה תיקייה, ולכן החיבור ממשיך לעבוד גם אחרי עדכון.
- אחרי עדכון האפליקציה, קוד המנוע מועתק מחדש. אם `uv.lock` השתנה, החבילות מסונכרנות שוב.
- החתימה היא ad-hoc, כי אין חשבון Apple Developer. לכן צריך לאשר פעם אחת ב-Gatekeeper. המדריך לעמיתים: [docs/colleagues-install.he.md](docs/colleagues-install.he.md).
- `scripts/dist.sh` (הבנייה של קלרה) ממשיך להריץ את המנוע מהתיקייה הזאת, דרך `engine-path.txt`.

## חיבור ל-Claude

**אוטומטי:** בכל הפעלה, האפליקציה מוודאת שהשרת `klara-wisper` (MCP) מחובר ל-Claude Desktop ול-Claude Code. היא מתקינה ומעדכנת את שלושת הסקילים ב-`~/.claude/skills`. ב-Claude Desktop צריך לסגור ולפתוח פעם אחת.

**ידני:** הגדרות > Claude > חיבור.

**סיכום אוטומטי:** הגדרות > Claude > "התחברות ל-Claude". זה צעד חד-פעמי: נפתח Terminal ואחריו דף התחברות בדפדפן. אחרי זה:
- כל שיחה מסוכמת דרך Claude Code (`claude -p`), עם המנוי הרגיל ובלי מפתח API. Claude מקבל רק שלושה כלים (`get_transcript`, `save_meeting_notes`, `set_meeting_details`), בלי גישה לקבצים, לרשת או לפקודות.
- בפעם הראשונה אחרי ההתחברות Claude עובר גם על כל השיחות הקודמות שאין להן סיכום, מהחדשה לישנה, אחת בכל פעם.
- בזמן שיחה הוא מחכה, כדי לא להאט את התמלול החי.

השרת רץ על ה-Python של המנוע (`engine/.venv/bin/python -m klara_engine.mcp_server`), ולא על האפליקציה עצמה. תוכן התמלולים מוחזר ל-Claude מסומן כ"מידע, לא הוראות", כדי שמשפט שמישהו אמר בפגישה לא יוכל להפעיל את Claude.

הכלים ש-Claude מקבל:
- `list_meetings`
- `search_transcripts`
- `get_transcript`: מזהה פגישה, `latest` לפגישה האחרונה, או `live` לשיחה שמתנהלת עכשיו.
- `list_dictations`
- `list_upcoming_meetings`
- `save_meeting_notes`
- `set_speaker_name`
- `set_meeting_details`: שם, משתתפים ונושא לשיחה שאין לה אירוע ביומן. שם מהיומן ושם שהמשתמש נתן לא נדרסים.

**הסקילים** (ב-[skills/](skills/)):
- `klara-meeting-prep`: לפני שיחה.
- `klara-live-catch-up`: במהלך שיחה.
- `klara-meeting-summary`: אחרי שיחה.

## הרשאות macOS

ההרשאות שהתוכנה צריכה: מיקרופון, הקלטת אודיו מערכת, נגישות (להדבקה), ניטור קלט (מקש fn), יומן, ואוטומציה ל-Chrome/Safari (לזיהוי Meet/Teams בלשונית). מסך ההקמה מבקש את כולן.

כדי ש-`fn` ישמש להכתבה: הגדרות מערכת > מקלדת > "לחיצה על 🌐" > "אל תעשה דבר".

אחרי בנייה מחדש של העוזר (`scripts/build-helper.sh`), macOS עשוי לבקש את ההרשאות שוב.

## אבטחה

- **האפליקציה:**
  - חתומה עם Hardened Runtime.
  - ה-Electron fuses נעולים: אין RunAsNode, NODE_OPTIONS או --inspect, והקוד נטען רק מתוך app.asar החתום.
  - החלונות רצים ב-sandbox, אין ניווט החוצה, וכל בקשת הרשאה מדף נדחית.
  - כל קריאת IPC נבדקת שהגיעה מדף של האפליקציה.
- **העוזר של macOS** (מחזיק את הרשאות המיקרופון, האודיו והנגישות):
  - בגרסת release הוא מקבל רק `serve`, ורק מהאפליקציה Klara Wisper עצמה, אחרי בדיקת חתימה של התהליך שהפעיל אותו.
  - חתום עם Hardened Runtime ומנקה משתני `DYLD_*`.
  - פקודות הבדיקה (`mic-test`, `tap-test`, `calendar`…) קיימות רק ב-`bash scripts/build-helper.sh debug`.
- **המנוע:**
  - מאזין רק ל-127.0.0.1.
  - הטוקן מגיע ב-stdin ולא בסביבה, ובקשות מדפי אינטרנט (עם Origin) נדחות.
  - המודלים נעולים ל-commit מסוים ונבדקים מול SHA-256 לפני כל טעינה.
- **קבצים:** כל קבצי המידע נוצרים עם הרשאות 600/700. ההקלטה של טביעת הקול נמחקת אחרי שנוצרה ממנה הטביעה.

## מבנה הקוד

- `src/main`: Electron main (זיהוי שיחות, הקלטה, הכתבה, שמירה, אינדקס, tray).
- `src/renderer`: הממשק (React + Tailwind): ספרייה, פאנל לייב, גלולת הכתבה, הגדרות, הקמה.
- `engine/klara_engine/mcp_server.py`: שרת MCP ל-Claude.
- `native/KlaraHelper`: עוזר ב-Swift:
  - מיקרופון וסריקת מיקרופונים
  - Core Audio process tap
  - זיהוי אפליקציות שמשתמשות במיקרופון
  - לשוניות דפדפן
  - מקש fn
  - הדבקה
  - EventKit
  - קידוד AAC
- `engine/`: מנוע Python (Whisper, VAD, Nemotron, טביעות קול). בדיקות: `cd engine && .venv/bin/pytest -s`.
- `scripts/e2e.cjs`, `scripts/e2e-short.cjs`: בדיקות מקצה לקצה על האפליקציה האמיתית.
